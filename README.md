## 🚀 Featured Projects

### 🔹 FPGA Music Player — Dual-CPU SoC (SystemVerilog)
Dual-processor WAV music player on the **DE1-SoC**, architected under the **ESL SER methodology (SM → PSM → TLM → CAM)**, partitioning the system into an **HPS/ARM Cortex-A9 audio-data plane** (Yocto Linux, triple-buffer shared-RAM IPC) and a **bare-metal NIOS II control plane**. Integrates 10+ IP blocks via Platform Designer with a documented MMIO register map, interrupt-driven playback FSM, and custom SystemVerilog modules validated through **UVM testbenches with self-checking scoreboards**.
👉 **Repo:** https://github.com/Adriel23456/FPGA-MusicPlayer-HPS-NIOS  
`SystemVerilog · SoC · UVM · HW/SW Co-Design`

---

### 🔹 Out-of-Order CPU Simulation Framework (C++)
Modular simulation framework for **computer architecture**, featuring a multi-core **TLP CPU simulator** with 2-way set-associative shared L1 cache, hazard detection, cache snooping, and interconnect bus modeling, plus a full **Tomasulo out-of-order core** with ROB, reservation stations, CDB, AGU, and speculative branch recovery.
👉 **Repo:** https://github.com/Adriel23456/ComputerEngineeringRecap  
`C++ · Computer Architecture · Microarchitecture Simulation`

### 🔹 Autonomous Vacuum Cleaner — Embedded Linux (C · Yocto)
Embedded system on **Raspberry Pi 4** running a custom **Yocto Linux image** (Scarthgap) built from scratch with a proprietary meta-robot BitBake layer. Includes 10+ hardware driver shared libraries (HC-SR04, MPU-6050 over I²C, L298N H-bridge with hardware PWM, GPIO) and a 5-thread C architecture with seqlock-based lock-free state sharing.
👉 **Repo:** https://github.com/dduarteCE/Robot-vacuum  
`C · Yocto · Embedded Linux · Device Drivers`
